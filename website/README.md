# Parafix web sitesi

Turkce tanitim sitesi. Flutter uygulamasindan bagimsizdir; mobil build ayarlarini degistirmez.

Yerel onizleme:

```sh
python3 -m http.server 4173 --directory website/dist
```

Ardindan http://localhost:4173 adresini ac.

Yayinlanacak klasor `dist/`. Statik hosting destekleyen bir servise yuklenebilir; Node.js, veritabani veya sunucu uygulamasi gerektirmez. Alan adi secildiginde canonical URL, sosyal paylasim meta verileri ve gizlilik politikasi baglantisi eklenmelidir.

Ekran goruntuleri gercek uygulamadan alinmistir. Tema karti renk onizlemesidir, uygulamanin etkileşimli bir kopyasi degildir. Yazi tipleri Google Fonts'tan yuklenir; baglanti olmadiginda yerel sans-serif yedegi kullanilir. Sitede analitik veya veri toplayan form yoktur.
